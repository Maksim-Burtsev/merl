### Fixed

- `d` in Ruby on a method a class gets from an included module no longer jumps into a string of that class that spans lines and holds a `def` of the same name (`%q{…}`, `%Q(…)`, `%(…)`, `%w[…]`, `"…"`, `'…'`): it lands on the module's method, and a class or method written in such a string elsewhere in the project is no longer offered beside the real one (#1422)
