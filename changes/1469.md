### Fixed

- `d` on a member at the end of a call chain headed by a static or companion factory (`Kettle.builder().size(2).build().boil()` in Java and Kotlin) follows each link's declared return type and lands on that type's member instead of a picker of every namesake, and in TypeScript a chain of calls with declared returns (`shop.counter().kettle().boil()`, `Kettle.builder().size(2).build()`) keeps its type past the first call; a link with no declared return still opens the picker (#1469)
