### Fixed

- `d` in Rust on a function or type declared inside a function body under the same name as one the file imports (`use crate::kettle::steep;` and a `fn steep()` inside a function) no longer jumps to the imported one: it offers the declarations by name, the local one first; and on the declaration of a method or an associated constant named like an import (`impl Infuser { fn steep(&self) }`) it no longer jumps to the imported function (#1410)
- `d` in Rust on a call above a function or type declared later in the same function body under an imported name (`steep(2);` then `fn steep()`) no longer jumps to the imported one: it offers the declarations by name, the local one first (#1410)
