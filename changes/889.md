### Added

- The tree and the review panel move by the page keys while they have the focus: `PgUp` / `PgDn` a page, `Home` / `End` (with `Ctrl` or without) the first and the last row, `Ctrl+D` / `Ctrl+U` half a page, and `{` / `}` the previous and the next folder row, the last row past the last folder. These keys used to move the code behind the tree (#889)
