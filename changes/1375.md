### Fixed

- `d` in Julia on a type after `::` (`i::Integer`, `bc::Base.Broadcast.Broadcasted`) looks the type up instead of a member of the value, so a type from Base or a package is found; a type parameter of a `where` or a `struct` still is not (#1375)
- `d` in Julia on the variable of a `catch err` block lands on that `catch` (#1375)
- `d` in Julia on a parametric alias (`AbstractVector`, `AbstractMatrix`) lands on its `const AbstractVector{T} = AbstractArray{T,1}` (#1375)
