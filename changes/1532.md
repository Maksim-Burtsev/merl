### Fixed

- A save that fails, on a full disk for one, no longer leaves the file empty on disk: merl first writes the new text to a file beside it and touches the file itself only once that whole write went through, so on a full disk the file keeps its old text and `save failed` says why, without a `changed on disk` that would offer to reload the empty file. The file is still written in place, so its links, permissions, owner, Finder tags and creation date stay; review notes are saved the same way (#1532)
