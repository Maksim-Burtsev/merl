### Fixed

- `d` in Python reads a generic function's return type (`def make[T]() -> Cup:`), takes no constraint tuple (`[T: (str, bytes)]`) for a class's bases or a function's parameters, and lands on a def's own `[T]` before a module-level `T = TypeVar("T")` (#1459)
- `d` in Python lands on the `[T]` of a type-parameter list wrapped over lines (`def f[` / `    T,` / `](x: T):`) and of a `type Pair[T] = …` alias before a module-level `T = TypeVar("T")`, and a local or parameter of that wrapped def still wins (#1459)
