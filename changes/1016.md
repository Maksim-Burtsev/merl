### Added

- `d` on an `@path` import in Markdown, as `@AGENTS.md` in a `CLAUDE.md`, opens that file and says
  `import AGENTS.md`. The path is read as Claude Code reads it: from the file's own folder, up to
  the first space not escaped as `\ `; code spans, fences and e-mail addresses are no imports, and
  an `@word` that names no file says `no file` and the path it looked for (#1016)
