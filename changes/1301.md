### Fixed

- `d` in C# on a method of a class whose base class is outside the project, such as `Find` in `basket.Find(…)` with `class Basket : List<Item>`, no longer jumps straight to the project's extension method of that name: the base may declare its own `Find`, which C# calls first, so `d` offers the extension in a picker. An interface outside the project, such as `IEquatable<Order>`, still jumps (#1301)
