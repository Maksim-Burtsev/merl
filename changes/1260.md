### Fixed

- `d` in SQL on a column reads the scope of a CTE that shares a table's name and the UNION branch the cursor is in: a column inside the CTE's own body (`WITH samovars AS (SELECT spout FROM samovars)`), in an outer query whose subquery declares the CTE, or in a UNION branch that reads only one table lands on that table's column, where it said "no definition"; a column in a CTE's body no longer jumps to a CTE declared after it in the same `WITH`, which it cannot see (#1260)
