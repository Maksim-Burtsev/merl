- `d` in Ruby on a method that a class defines and a module it prepends defines too lands on the module's method, which Ruby calls first, not on the class's own (#1432)
- `d` in Python on `self.pour(…)` in a class whose `__init__` sets `self.pour = …` lands on that assignment, not on the `pour` the class inherits, which the assignment hides (#1432)
