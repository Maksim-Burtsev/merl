### Fixed

- `d` in PHP on a method or property of a vendor class the project also declares as an empty stub, as IDE helper files do, lands on what the vendor class declares when the receiver is a typed parameter, a `new` binding or a typed `$this->field`, where it offered, or jumped to, a namesake by name; the same holds for a vendor class whose parent the project stubs, where it found nothing. A project class of that name that declares the member, takes it from a trait or a parent, or answers it through `__call`, `__callStatic` or `__get` keeps the search it had (#1323)
