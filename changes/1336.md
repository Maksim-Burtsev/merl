### Fixed

- `d` in C++ on a struct declared inside a function goes to the one in scope: a namesake declared inside another function of the file no longer joins a picker, and the innermost one in scope hides the rest (#1336)
- `d` in C++ on a class template's name in `Ladder<K, C>::Iterator::Seek` goes to the class: the line that defines a nested class out of line, `struct Ladder<K, C>::Rung {`, no longer counts as a declaration of `Ladder` (#1336)
- `d` in C++ on a type name inside a class's method goes to the class's own nested type before a namesake of the namespace (`Writer` in `DBImpl::BuildBatchGroup` is `DBImpl::Writer`, not `log::Writer`), and outside the class a nested type no longer joins the namespace's type in a picker (#1336)
- `d` in C++ on a method declared in a class goes to that class's out-of-line definition with the same parameters, not to a picker of every namesake method (`void Clear();` in `VersionEdit` to `VersionEdit::Clear()`) (#1336)
