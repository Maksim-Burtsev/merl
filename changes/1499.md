### Fixed

- `d` on a Kotlin, Scala, Swift, C# or Rust extension declared in two packages, modules or namespaces lands on the one the file imports instead of offering both (#1499)
- `d` on a member of a Dart `extension … on T`, a Scala 2 `implicit class C(x: T)` or a TypeScript `declare module` augmentation lands on the extension of the receiver's type (or of a type it extends or mixes in) instead of offering every namesake, and a class's own method in a file that augments it lands on the class (#1499)
- `d` on a member of an unnamed Dart `extension on T` (in the same library) or of an extension on a generic type (`extension X<T> on Box<T>`) lands on it instead of offering every namesake, and a Dart parameter after a generic one (`Box<int> box, Jar<String> jar`) is no longer read as the first one's type (#1499)
