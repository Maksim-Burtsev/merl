### Fixed

- `d` in Python on a name the file imports and then defines again itself, as a class or a function, jumps to the file's own definition, not to the imported one (#1407)
- `d` in Python on a method of a variable made from a class the file imports, `x = Cup()` or `x: Cup`, jumps to the imported class's method when the file defines its own `Cup` too but the import is the later binding (#1407)
