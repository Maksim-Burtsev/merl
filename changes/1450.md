### Fixed

- `d` on a method called through a `this` or `self` that a nested construct rebinds no longer lands on the enclosing class's method: a `function` opened on the same line in TypeScript and JavaScript, `instance_eval` / `instance_exec` / `class_eval` / `module_eval` blocks in Ruby, and `.with { }` / `.tap { }` closures in Groovy now offer a picker, or the receiver's method when its type is written (#1450)
