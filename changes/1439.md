### Fixed

- `d` on a type parameter named like a type of the project (`class Box<Cup>` beside a `class Cup`) lands on the parameter inside its generic in TypeScript, Java, Kotlin, Scala and Dart, instead of on the type (#1439)
- `d` on such a type parameter also lands on it when the generic wraps its `<…>` list over several lines, in TypeScript, Java, Kotlin, Scala and Dart (#1439)
- `d` on a type parameter after an argument whose type wraps over lines (`function f<A>(x: A, y: Array<` … `>): A {`) lands on the parameter in TypeScript instead of finding nothing (#1439)
