httpx/_auth.py:238-239
>         for field in parse_http_list(fields):
>             key, value = field.strip().split("=", 1)
agent: I should have caught this earlier. parse_http_list only understands double quotes, so qop='auth,auth-int' gets split at the comma, and "auth-int'" has no "=", so this line raises ValueError. RFC 7616 only allows double-quoted strings anyway. Single-quote support only works when the value has no comma. Do we keep it with that limit, write our own splitter, or drop the feature?
