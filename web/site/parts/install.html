Install

Or a prebuilt binary from the releases, or cargo install --git https://github.com/Maksim-Burtsev/merl with Rust 1.95 or newer.

$ merl
the current directory
$ merl FILE:LINE[:COL]
what compilers, linters and grep print
$ merl --review
the branch you are on, as a diff over the real files
$ merl --tutor
every key, hands on, in about ten minutes
